Sizzle Street Kitchen is a fast, cheerful 2D cooking game that plays offline in a desktop browser. Orders pin up on the board — Classic Burgers, Egg Stacks, Sunny Plates, Berry Pancakes and more — and you stack each dish ingredient by ingredient from the counter bins, sizzle patties, eggs and pancakes in the pan (serve in the green window or they burn), and serve at the pass before each customer's patience runs out. Coins, tips, combo streaks, rising levels and three lives keep the lunch rush tense. Everything is drawn in code on a canvas: the kitchen, the order board, the sizzling pan, the customers — no image assets, no network, just static files.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
# hand in the entry with: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
